images/

    front.jpg
    back.jpg
    side.jpg

or images/
  097582892096_front.jpg

The application indexes UPC/NAN_KEY/numeric filename tokens. When a ZIP is uploaded, all supported image files are extracted to short runtime-safe paths and every matched image is read.
